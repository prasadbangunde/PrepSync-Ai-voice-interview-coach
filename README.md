## 📖 Overview

PrepSync AI is an intelligent interview coaching platform designed to help job seekers improve their interview performance through AI-powered mock interviews and ATS resume analysis.

The platform simulates real interview experiences using voice conversations, evaluates responses, analyzes resumes against job descriptions, and generates personalized feedback to improve interview readiness.

## 🎯 How It Works

### Step 1: User Authentication
Users create an account and securely log in.

### Step 2: Resume Upload
Users upload their resume and provide a target job description.

### Step 3: ATS Analysis
The system analyzes the resume against the job description and generates:
- ATS Score
- Missing Keywords
- Resume Suggestions

### Step 4: Mock Interview
The AI generates interview questions and conducts a real-time voice interview.

### Step 5: AI Evaluation
Responses are analyzed based on:
- Relevance
- Communication Skills
- Technical Accuracy
- Confidence

### Step 6: Personalized Feedback
Detailed performance reports and recommendations are generated.
