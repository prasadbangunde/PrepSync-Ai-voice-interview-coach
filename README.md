# Prepwise – AI-Powered Voice Interview Coach

Prepwise is a full-stack AI interview preparation platform that simulates real-time voice interviews, evaluates candidate performance, analyzes resumes for ATS compatibility, and provides personalized improvement suggestions.

## Features

- AI-Powered Voice Interviews
- ATS Resume Analysis
- Resume & Job Description Based Questions
- Interview Performance Scoring
- Detailed AI Feedback Reports
- Job Role Recommendations
- Secure Authentication
- Dashboard for Interview History

## Tech Stack

Frontend
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Shadcn UI

Backend
- Next.js API Routes
- Prisma ORM
- PostgreSQL

AI Services
- Google Gemini
- Groq LLM
- Vapi Voice AI

Authentication
- JWT Authentication
- Secure Cookie Sessions
